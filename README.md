## I consult. I install. I write it down.

The work is **assess → specify → install → test → hand over**.

Listen first. Diagnose in layers. Explain in the language of the person who has to live with it. Leave a document the next person can extend.

> **Mission** — Make systems that people can actually inhabit. A system that exists only in a drawing is not finished. Neither is software nobody can log into.

I trained in urban and regional planning at the University of Lagos. That education stays in how I think, not in the headline of the work. A VLAN is a district. An ACL is a zoning rule. A runbook is development control.
